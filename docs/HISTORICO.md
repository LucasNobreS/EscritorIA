# Histórico anterior ao Git

Este inventário foi reconstruído a partir dos nomes dos pacotes preservados e dos READMEs que puderam ser abertos. Ele não substitui um diff entre versões nem certifica que todos os recursos anunciados funcionavam. Não atribuímos datas de lançamento sem evidência.

O primeiro histórico Git disponível começa com a importação dos fontes. As versões anteriores não têm commits ou tags retroativos neste repositório. Os ZIPs antigos ficam no arquivo histórico separado, não na árvore do código.
