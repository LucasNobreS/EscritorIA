## Manter estes guias

Ao alterar um fluxo, atualize seu guia e o changelog no mesmo commit. Ao mudar configurações ou caminhos, confira também instalação e backup. Antes de publicar uma release, registre testes realizados e limitações conhecidas. Documentação de processo não é evidência de que uma etapa já foi executada.
